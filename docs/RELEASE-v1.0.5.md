くらしスクエア文書ダウンローダーの初回GitHubリリースです。Python版とexe版は同じソース・バージョンで提供します。

- カテゴリー・年度・文字検索をAND条件で利用できます。
- 年度は一覧の「年月／期」で判定します（4月～翌年3月）。
- 手動改名と重複保存の抑止に対応します。
- 本体MIT LICENSEと第三者ライセンス通知を整理しました。

通常の利用はexe.zipを選んでください。Python版には実行環境を同梱しています。利用する版のdocuments.zipも併せて取得してください。再配布時も両ZIPを一緒に提供してください。

Windows / Microsoft Edgeが必要です。OCRを使う場合はTesseractと日本語データを別途用意してください。

検証：90件の自動テスト、配布版の起動・OCR有無の自己診断を確認済み。GitHub登録時のソース整理後も自動テストを実行しています。実サイトでの通信は今回の登録作業では再検証していません。
